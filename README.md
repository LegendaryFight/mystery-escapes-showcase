# Mystery Escapes — Frontend Project Showcase

## Overview

Mystery Escapes is a mock hotel and flight booking website developed as a second-year group project at the University of Liverpool.

This repository showcases my frontend contribution. It is a university demonstration project, not a commercial booking service, and does not process real payments.

## My Contribution

I contributed to the development of frontend pages using React as part of the project team. My role focused on the frontend rather than backend development.

## Technologies

- React
- HTML
- CSS
- Git and GitHub
